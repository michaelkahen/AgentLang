AgentLang accepts ordinary Python plus fused, one-letter collection stages on a single physical line: x = source:w expr:m expr:l, return source:..., or j source:.... The stage spellings are :w EXPR filter, :m EXPR map, :f EXPR flatten one iterable per input, :n count, :u [EXPR] sum, :a [EXPR] mean, :s [EXPR] stable sort, :c N Counter.most_common, :h first and :l list. _ is the current item; :w, :m and :f produce generators. j expr writes default JSON and p expr prints; both commands require a space after the letter. Do not nest a pipeline inside another expression. Use at least one of these short collection stages on task data as part of computing the requested result. Output commands and helper calls alone do not satisfy this requirement.
