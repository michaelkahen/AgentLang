# Where the four workloads came from

Each workload reproduces an operation found in a public model-generated Python tool call. The standalone Python scripts are adaptations written for this experiment. Each works on local, invented data, so the reference answers below differ from the original datasets. Token and runtime measurements use the files in this directory.

| Script | Observed agent action | Adaptation for the benchmark |
| --- | --- | --- |
| `late_flights.py` | Qwen3-Coder-480B executed a pandas cell counting US Airways rows marked both negative and Late Flight. Jupyter-Agent record `0016/712/16712977.ipynb_qa_5`. [View the trace](https://huggingface.co/datasets/jupyter-agent/jupyter-agent-dataset/viewer/default/non_thinking?row=2) | Read a local UTF-8 CSV with Python's `csv` module, apply the same three exact predicates, and print the count. |
| `goal_gap.py` | Qwen3-Coder-480B executed a pandas cell computing the difference between failed and successful Kickstarter projects' mean USD goals. Jupyter-Agent record `0045/672/45672139.ipynb_qa_3`. [View the trace](https://huggingface.co/datasets/jupyter-agent/jupyter-agent-dataset/viewer/default/non_thinking?row=0) | Load a local CSV using the standard library, calculate both means, and print their difference to two decimal places. |
| `word_counts.py` | Qwen3-1.7B used a Python interpreter to split a list of strings, count the resulting words, and select the most frequent one. AgentTrace MBPP task 326, trace `e2f6fe16-839b-488c-9091-c46b56a5deab`, line 316 in the [pinned trace file](https://huggingface.co/datasets/pagarsky/agent-trace/blob/4b05b2f00eea267a5bb4d841c228059d1bf9ac0c/datasets/mbpp_1_7B_20260403T211347Z.jsonl). | Read JSON sentences from stdin and feed a generator to the same `Counter.most_common(1)` operation. A tie in the fixture exercises first-seen order. |
| `sort_scores.py` | Qwen3-1.7B used a Python interpreter to sort pairs by their second element using a key function. AgentTrace MBPP task 487, trace `f00cb3e7-b702-4fbb-b1ae-996319716b96`, line 477 in the [pinned trace file](https://huggingface.co/datasets/pagarsky/agent-trace/blob/4b05b2f00eea267a5bb4d841c228059d1bf9ac0c/datasets/mbpp_1_7B_20260403T211347Z.jsonl). | Read pairs of names and numeric scores as JSON from stdin, stable-sort by score, and emit JSON. The fixture includes tied scores and an accented name. |

The two notebook records are from the `non_thinking` split at revision `10a8dd461bb6c580fa25b83cd3b2f6810f1d6385`. Both have `executor_type=e2b` and include the assistant's Python cell and its sandbox response. The benchmarks omit the notebooks' exploratory cells and use Python's standard library to keep the two implementations' dependencies comparable. [Dataset methods and revision](https://huggingface.co/datasets/jupyter-agent/jupyter-agent-dataset/blob/10a8dd461bb6c580fa25b83cd3b2f6810f1d6385/README.md)

The remaining two records come from an agent solving programming exercises in a Python tool. They establish observed use of each operation in a controlled setting. Frequency of use in production agent sessions is outside this sample. [AgentTrace collection methods](https://huggingface.co/datasets/pagarsky/agent-trace/blob/4b05b2f00eea267a5bb4d841c228059d1bf9ac0c/README.md)
